# Communi Watch

## ?? Overview
Communi Watch is a community monitoring and reporting platform built to surface issues quickly and keep local operations informed. It focuses on clear reporting workflows and fast visibility.

## ? Problem
Community issues are often reported through informal channels, which leads to delays, missing data, and slow response.

## ?? Solution
I built a structured reporting interface with clear status states, streamlined submission, and a layout optimized for rapid triage.

## ?? Tech Stack
* Frontend: HTML / CSS / JavaScript
* Backend: REST APIs (integration-ready)

## ? Features
* Issue reporting workflow
* Status tracking and triage views
* Responsive layout
* Clean, accessible UI
